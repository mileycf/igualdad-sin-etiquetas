# Igualdad sin etiquetas

Sitio educativo desarrollado con Astro para cuestionar los prejuicios asociados al género en las profesiones y los oficios.

## Requisitos
- Node.js instalado
- Visual Studio Code (recomendado)

## Ejecutar el proyecto
1. Descomprime la carpeta.
2. Abre la carpeta `igualdad-sin-etiquetas` en Visual Studio Code.
3. Abre la terminal dentro de VS Code.
4. Ejecuta:

```bash
npm install
npm run dev
```

5. Abre en el navegador la dirección local que aparece en la terminal (normalmente `http://localhost:4321`).

## Páginas
- `/` — Inicio
- `/tema` — Explicación de los estereotipos de género
- `/recursos` — Acciones para promover la igualdad

## Componentes reutilizables
- `Navbar.astro`
- `Footer.astro`
- `Hero.astro`
- `Card.astro`

## Antes de entregar
- Revisen y personalicen los textos si lo necesitan.
- Actualicen `prompts.txt` con cada prompt real que utilicen durante el desarrollo.
- Prueben `npm run build`.
- Suban la carpeta completa a GitHub y agreguen a `profeenrique` como colaborador.
